방금 내용 검수에서 직접 읽어 확인한 최신 구현 상태를 최종 HTML에 모두 반영한다. 네 copy_patches 중 1·2·4·8·9·10·13·14·16번은 반영했으며, 별도 가독성 검수자가 준 11·15·17·18·21·24·26·27번 교정도 반영 중이다. 화살표 위치와 괄호 뒤 조사 줄바꿈은 HTML에서도 수정한다.

네 최신 코드 확인 결과: 학습 문항/노트 보상, Series A/B, 시장 순위/서랍/전광판, 사옥 성장/불빛, 교사 전광판 마감/프로젝터 보기가 연결되어 있다. 교사의 시계/수동 심사 버튼만 연결 중이다. 이 사실은 최초 원고보다 우선한다.

아래 누락된 최신화 문구를 네가 완성해 줘. 추가 소스 조사나 이미지 도구 호출 없이 방금 직접 확인한 내용을 바탕으로 JSON {"patches":[...]}만 출력한다.
