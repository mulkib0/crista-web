# CRISTA 교사 연수 — Relay

## 시각적 방향
아이보리 종이에 정밀한 검은 활자와 투명한 무지개빛 과학 오브젝트를 놓은 과학 전시 도록. 사용자에게 승인된 `crista-science/*.png`의 재질·색감·여백을 HTML로 재구성한다.

## 구성
도입 → 개발본 범위 → 과학 원리 → 학생 화면/협업 → 단계별 탐구 → 교사 운영 → 실습.

## 반복할 체계
표지/섹션은 큰 제목과 그림, 설명은 그림+3~4행, 비교는 두 열, 흐름은 연결된 순서, 화면 설명은 도식, 마무리는 실습 안내로 구성한다. 과학 원리에서 한 차례, 단계 설명에서 한 차례 밀도를 낮춘 화면을 배치한다. 화면 조작 도구는 슬라이드 바깥에 둔다.

## 토큰
- background: #f1f1e9
- surface: #fbfbf6
- primary text: #080b09
- muted text: #52574f
- line: #c7cbc1
- accent: #080b09 (유리 이미지 내부의 무지개 간섭색은 승인된 예외)
- font: Relay체만 사용, Regular 400 / SemiBold 600
- display: 40~48pt / headline: 28~34pt / body: 14~17pt / caption: 10~11pt
- frame: 720pt × 405pt
- 한국어 word-break: keep-all, 제목 text-wrap: balance
- 좁은 테두리와 정렬로 구분하고 카드·그림자·밝은 색 바탕을 반복하지 않는다.
