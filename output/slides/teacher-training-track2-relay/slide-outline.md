# CRISTA 항체 설계 랩 (트랙 2) 교사 연수 — 구성

문구: Gemini 4 Argon (High)

## 01. 교실 속 바이오 스타트업, 항체 설계 랩 탐구 수업
- 구성: cover / 개념 안내
- 핵심: 복잡한 파이썬 설치 없이 브라우저에서 항체 서열과 3D 구조를 다루며 합의로 설계합니다.

## 02. Colab 노트북 일제 실습의 한계와 웹 항체 랩의 해법
- 구성: contrast / 설계 방향
- 핵심: 원본 AI 항체 실습 노트북의 과학적 질문은 살리고 교실 모둠 협업 구조를 더했습니다.

## 03. 저분자 신약 랩(트랙 1)과 항체 설계 랩(트랙 2)의 차이
- 구성: compare / 개념 안내
- 핵심: 세포 안 주머니를 노리는 저분자 약과 세포 표면 수용체를 막는 항체 약의 차이를 비교합니다.

## 04. 네 가지 질문으로 따라가는 항체 설계 4묶음 6단계
- 구성: roadmap / 개념 안내
- 핵심: 누구를 본뜰까, 어디를 바꿀까, 제대로 접히고 붙을까, 약으로 쓸 만할까의 네 질문이 이어집니다.

## 05. 항체 설계 랩 구현 범위와 교실 네트워크 안전망
- 구성: status / 현재 화면
- 핵심: 사이드바 하단에 실시간 조회, 저장 결과, 고정 자료 중 현재 데이터 상태가 투명하게 표시됩니다.

## 06. 실제 데이터·AI 추론과 교육용 근사를 가르는 5종 배지
- 구성: science / 개념 안내
- 핵심: 근사값에는 원전 학술 지표명을 붙이지 않고 우리말 개념 이름을 써서 과학적 오해를 막습니다.

## 07. 항체 가변부위(Fv) 구조와 IMGT 표준 자리 번호
- 구성: science / 개념 안내
- 핵심: 단순 정규식이 아닌 실측 항체 DB 번호 매김으로 고유 중쇄 6,609개에서 CDR 경계를 검증했습니다.

## 08. 다중서열정렬(MSA)과 항체 레퍼토리 다양성 읽기
- 구성: science / 개념 안내
- 핵심: '진화적 보존 패턴이 3D 구조의 단서가 된다'는 원리를 항체 레퍼토리 특성에 맞춰 정확히 가르칩니다.

## 09. 변이 설계의 물리화학 지표와 약점 모티프 점검
- 구성: science / 개념 안내
- 핵심: 승인 치료항체 151종의 실측 분포로 감점표를 보정해 실제 약의 물성 기준을 교실에서 체감합니다.

## 10. 단량체 3D 접힘 예측과 항원-항체 복합체 평가
- 구성: science / 개념 안내
- 핵심: 단일서열 접힘 모델이 점변이를 잘 구별하지 못한다는 한계까지 학생에게 정직하게 안내합니다.

## 11. 연구소 고르기부터 사옥 등기와 항체 랩 진입까지
- 구성: flow / 현재 화면
- 핵심: 교사가 학급 설정에서 오늘 수업에 쓸 트랙만 열어 두거나 두 트랙을 모두 열어 비교할 수 있습니다.

## 12. 개인 서열 실험과 모둠 비교표를 나눈 네 개의 섬
- 구성: workspace / 현재 화면
- 핵심: 모든 3D 구조 뷰어 옆에 같은 정보의 데이터 표 탭을 나란히 두어 기기 성능과 무관하게 수업합니다.

## 13. 한 명 독점을 막는 분담 카드와 과반 투표·쿼터제
- 구성: collaboration / 현재 화면
- 핵심: 데이터베이스 유일 제약으로 1인 설계·평가 상한을 고정해 모둠원 네 명이 모두 실험에 참여합니다.

## 14. A1 표적 선정부터 A6 상장 평가까지 6단계 흐름
- 구성: steps / 현재 화면
- 핵심: A1~A4를 무료로 열어 충분히 탐색하게 하고, A5 평가와 A6 최종 제출에서 신중히 예산을 쓰게 합니다.

## 15. 3대 암 표적 항원과 기준 승인 치료항체 3종 비교
