# 지시문 — 3.2 전임상 · 동물실험 학생용 문구 초안 (Gemini 4 Argon High)

너는 교육용 신약 개발 시뮬레이션 'crista-web' 의 학생용 화면 문구를 쓰는 작가다.
이 단계는 **3.2 전임상 · 동물실험**이다. 학생 모둠(= 스타트업 제약회사, 4명)이 특허받은 분자로 동물실험을 하기 전에 동물실험 윤리를 배우고, 계획서를 써서 윤리위원회 심의를 받고, 대체 시험과 동물실험을 한 뒤, 결과판을 읽고 주력 · 백업 분자를 한 번 더 고른다.

파일을 고치지 말고, 결과를 **표준 출력으로만** 내라. 저장소 파일을 읽을 수는 있지만, 아래 발췌가 사실의 기준이다. 발췌와 다른 사실을 쓰지 마라.

---

## 1. 문체 규칙(반드시 지킬 것 · 6개)

1. 독자는 수업을 듣는 학생(중 · 고등학생 수준)이다. 전문어는 처음 나올 때 괄호로 푼다. 예: `NOAEL(부작용이 보이지 않은 가장 높은 용량)`.
2. 한 문장에 한 생각. 존댓말 해요체.
3. 숫자는 서버 값 자리표시자(`{mrsd}` · `{dG}` · `{n}` 등) 그대로 둔다. 자리표시자를 새로 만들면 표의 '자리표시자' 칸에 적는다.
4. 설계 문서의 사실(법 조항 · 통계 · 지침 · 공식 · 금액 · 기간 · 문턱값)을 바꾸지 않는다. 과학적으로 틀린 비유를 쓰지 않는다.
5. 화폐는 '크리스타'. 화면에 `$` 를 쓰지 않는다.
6. '텃밭' 같은 다른 저장소 용어는 쓰지 않는다. 모둠 = 스타트업 제약회사.

추가 주의:
- 동물실험을 '나쁜 것'이나 '괜찮은 것'으로 단정하지 마라. 법 · 지침이 요구하는 이유와 3R 로 줄이는 방법을 담담하게 설명한다.
- 동물의 고통을 자극적으로 묘사하지 마라. 장난스러운 말투 · 이모지 금지.
- 규칙 값(46 · 82 · 141마리, 안전계수 10 · 20, 환산 계수 6.2 · 1.8, 60 kg, 80%, 0.7, 1~50, 10자, 하루 5회)은 설계 그대로다. 서버가 바꿀 수 있는 값은 자리표시자로 쓴다(아래 '이미 있는 자리표시자').

## 2. 범위(빠짐없이)

1. 걸음 이름과 단계 설명('이 단계에서 하는 일')
2. ① 윤리 교육 — 윤리 카드 5장(제목 · 본문 · 출처), 확인 문제 3개(질문 · 보기 · 정답 해설 · 오답 해설), 이수 · 재도전 안내, 딜레마(생각해 볼 거리)
3. ② 동물실험계획서 — 칸 6개(목적 · 필요성 / 대체 / 감소 / 개선 / 종 · 이유 / 실험 수행자)마다 **칸 안내 + 예시 문장 한 줄**, 마릿수 수준 3개 설명, 규칙 검사 문구(통과 / 실패), 심의 결과 · 상태 문구, 변경 심의 안내
4. ③ 대체 시험 — 시험 2종 이름 · 보는 것 · 결과 설명, '새 판정을 만들지 않는다' 안내, 덜 쓴 동물 수
5. ④ 동물실험 — 묶음 4종 설명, 진행 · 실행 문구, 재실행 안내, NOAEL → HED → MRSD 계산 칸 안내 · 공식 · 맞음 / 틀림
6. ⑤ 결과판 · 주력 / 백업 지정 — 결과판 지표 이름과 풀이, 근거 칩 5개(이름 · 맞음 · 주의 · 막음 문구), 주력 · 백업 규칙 안내, 동물실험 종료보고서 · 회고 안내
7. 공통 — 잠김 · 선행 조건 메시지, 완료 조건, 전광판 헤드라인

## 3. 화면 자리

3.2 는 디자인 시안에 없던 단계라, 공통 틀인 **시안 21 '둥근 섬'** 으로 만든다. 왼쪽 사이드바(단계 목록) · 가운데 **'내 작업대'** 섬 · 오른쪽 **'모둠 공유'** 섬 · 위쪽 **전광판 01**(LED 흐르는 띠). 걸음 탭 ①~⑤ 가 섬 위에 있다.

| 걸음 | 왼쪽 · 내 작업대 | 오른쪽 · 모둠 공유 | 다음으로 |
| --- | --- | --- | --- |
| **① 윤리 배우기**(실험 수행자 교육) | 윤리 카드 5장 + 확인 문제 3개(규칙 채점 · 다시 풀기 무제한) | 모둠원별 '교육 이수' 도장 | 동물실험 **실행 단추를 누르는 사람만** 이수가 필요하다(동물보호법 제47조 ③ — 실험은 윤리적 취급과 과학적 사용의 지식을 갖춘 사람이 한다). 읽기 · 계획서 쓰기 · 결과 보기는 누구나 |
| **② 동물실험계획서 → 윤리위원회 심의** | 계획서 칸 쓰기(3R 근거 · 마릿수 · 고통등급 · 인도적 종료시점) | 칸 분담 · 심의 결과(승인 / 보완) | 승인 |
| **③ 대체 시험 먼저(선택)** | 세포 · 오가노이드 시험 2종 — 동물 0마리 | 후보별 결과 · 이 결과로 후보를 빼면 '덜 쓴 동물 수' 표시 | 막지 않는다 |
| **④ 동물실험 실행** | 승인된 계획서대로 특허 분자마다 한 묶음 | 진행(게임 시계) · 결과판 | 1건 이상 완료 |
| **⑤ 한 번 더 고르기** | 결과판 해석 · 근거 칩 | **주력 1 + 백업 0~1 지정** · 동물실험 종료보고서 | [3.3 제형 · IND 로] |

키의 '자리'는 `ethics` · `protocol` · `alt` · `animal` · `calc` · `pick` · `report` · `board` · `common` 중에서 고른다.

## 4. 설계 원문 발췌(사실의 기준 — 숫자 · 조항 · 공식 그대로)

실제 순서도 물질특허 → 전임상 → IND 이고, IND 신청서의 '비임상 시험 자료'(약리 · 독성)가 여기서 나온다(식약처 「의약품 임상시험 계획 승인에 관한 규정」 [별표 1] · 21 CFR 312.23(a)(8)).

### ① 윤리 카드 5장

| 카드 | 내용 |
| --- | --- |
| 1. 왜 동물에서 먼저 보나 | 사람에게 처음 주기 전에 '얼마까지 안전한가'를 재는 관문. 저분자 신약은 보통 **설치류 1종 + 비설치류 1종**의 반복투여 독성과 심장 · 중추신경 · 호흡 **안전성약리**를 본다(ICH M3(R2) · S7A · S7B) |
| 2. 3R | **대체**(Replacement — 동물 없이 답할 수 있으면 그 방법 먼저: 세포 · 오가노이드 · 컴퓨터) · **감소**(Reduction — 필요한 최소 마릿수, 단 통계적으로 믿을 수 있을 만큼은) · **개선**(Refinement — 마취 · 진통 · 사육 환경 · 인도적 종료시점으로 고통을 줄인다). 1959년 Russell · Burch 가 제안했고, 동물보호법 제47조(동물실험의 원칙)가 같은 내용을 적는다 |
| 3. 고통등급 A~E | A 생물개체를 쓰지 않거나 무척추동물 · B 척추동물이지만 거의 고통 없음 · C 약간의 스트레스나 짧은 작은 통증 · D 피할 수 없는 고통(진정 · 진통 · 마취제를 쓴다) · E 피할 수 없는 고통이고 약을 쓰면 결과가 망가지는 실험(원칙적으로 불허, 사유 필요). **D 는 고통 경감 조치가 반드시, E 는 경감할 수 없는 분명한 사유가** 있어야 한다(IACUC 표준운영가이드라인 — 농림축산검역본부 고시 제2023-47호) |
| 4. 인도적 종료시점 | 미리 정한 기준에 닿으면 실험을 끝낸다 — 예: 정상 체중의 20% 이상 감소 · 종양이 체중의 10% 초과 · 먹지 못함 · 마비(같은 가이드라인의 예) |
| 5. 숫자와 바뀌는 흐름 | 2024년 국내 실험동물 **4,592,958마리**, 마우스 81.5%, 고통등급 D · E 가 80.1%(농림축산검역본부 2024 실태조사). 동물에서 안전 · 유효해 보인 약의 **90% 이상이 사람에서 허가받지 못한다**(FDA 2025 로드맵). 그래서 FDA 현대화법 2.0(2022)이 비동물 방법을 IND 근거로 인정했고, FDA 는 2025-04 로드맵 · 2026-09 규정 개정으로 '동물 시험'을 '비임상 시험'이라 부르기 시작했다 — **동물실험을 금지한 것은 아니고, 더 나은 방법이 있으면 그것을 쓰라는 것** |

- 확인 문제 3개: ① 사례 → 3R 분류(예: '세포로 hERG 를 먼저 쟀다' = 대체) ② 실험 → 고통등급 매기기 ③ 인도적 종료시점 고르기. 학습 연구비 3.2 개념 문항과 같은 문항 은행을 쓰되, 교육 이수는 보상과 따로 기록한다.
- 이 교육은 '채점 안 받아도 진행을 막지 않는다'(학습 연구비 원칙)의 **유일한 예외**다 — 법이 실험 수행자에게 요구하는 것이라 실행 단추에만 걸고, 다시 풀기 무제한 · 모둠원 한 명만 이수해도 모둠이 진행할 수 있다.
- 심화 문항의 딜레마 예: "동물 수를 절반으로 줄이면 사람 1상의 시작 용량을 더 낮게 잡아야 한다(⑤). 어느 쪽이 더 윤리적인가?"

### ② 동물실험계획서(IACUC '동물실험계획 승인신청서'를 학생용으로 줄임)

| 칸 | 학생이 쓰는 것 | 서버가 채우는 것 | 심사 — 규칙 / LLM |
| --- | --- | --- | --- |
| 목적 · 필요성 | 왜 사람 전에 동물에서 봐야 하나 2~3줄 | 특허 분자 목록(코드명) | LLM: 목적이 IND 근거와 이어지나 |
| 대체(Replacement) | 대체 시험을 먼저 했나 · 무엇을 동물 없이 확인했나 · 왜 동물을 완전히 대체할 수 없나 | ③ 결과 | LLM: 이유가 구체적인가("법이라서"만이면 보완) |
| 감소(Reduction) | 넣을 후보(특허 분자 중) · 군당 마릿수 수준(적게 · 알맞게 · 많이) · 근거 | 총 마릿수 | 규칙: '많이'는 보완(근거 없는 과다) · LLM: 근거 서술 |
| 개선(Refinement) | 마취 · 진통 · 사육 환경 · 인도적 종료시점 기준(숫자) · 효력 모델의 고통등급 고르기 | 모델 정답 등급 | 규칙: 고통등급이 모델 표와 다르면 보완 · 종료시점 숫자 칸이 비면 보완 · LLM: D 등급이면 경감 조치를 적었나 |
| 종 · 이유 | 랫드 + 비글견(고정) 이유 한 줄 | — | LLM: 두 종이 필요한 이유를 이해했나 |
| 실험 수행자 | 교육 이수한 모둠원 고르기 | 이수 기록 | 규칙: 1명 이상 |

- 심의 = 규칙 검사 + LLM 심사관(동물실험윤리위원회 역할). 결과는 승인 / 보완. 무료 · 계획서 1건당 하루 5회.
- **승인된 계획서의 후보 · 마릿수 수준대로만** 실행된다. 후보를 더하거나 수준을 바꾸려면 변경 심의를 다시 받는다(실제 IACUC 의 변경승인과 같다).
- 서술 칸은 `{min}`자(현재 10자) 이상. 인도적 종료시점 숫자 칸은 체중 감소 % 정수 `{min}`~`{max}`(현재 1~50).
- 학생에게 보이는 LLM 심사 글에는 'AI 심사' 표시가 붙는다.

### ③ 대체 시험(선택 · 동물 0마리)

| 시험 | 보는 것 | 결과 | 비용 · 기간 |
| --- | --- | --- | --- |
| hERG 패치클램프(세포) | 심장 칼륨 통로를 얼마나 막나 | IC50 구간 — 2.2 hERG 신호와 같은 재료(염기성 아민 · cLogP)로 결정적 | 후보 · 시험당 50,000 크리스타 · 2게임 일 |
| 사람 간세포 · 간 오가노이드 독성 | 간세포 손상 | 독성 구간(세포 생존율) — 2.2 간독성 신호와 같은 재료 | 같음 |

- 대체 시험은 새 판정을 만들지 않는다 — 2.2 의 예측 신호를 **실험 값으로 굳혀** ② 계획서의 대체 칸 근거와 '이 후보는 동물실험에서 빼자'는 결정의 근거가 된다. 뺀 후보만큼 '덜 쓴 동물 수'가 결과판에 남는다.

### ④ 동물실험 묶음(특허 분자마다 · 교육용 단순화)

| 시험 | 종 · 마릿수(알맞게) | 보이는 결과 | 판정 재료 |
| --- | --- | --- | --- |
| 약동학(PK) | 랫드 6 | 경구 생체이용률 F% · 최고 농도 · 반감기 · (CNS 표적) 뇌/혈장 비 | 흡수 · 뇌 노출 |
| 효력(질환 모델) | 표적별 모델 군당 8 × 3군(질환 대조 · 기준 약 · 후보) = 24 | 기준 약 대비 효과 % | 결합력 · 흡수 · 뇌 노출 |
| 반복투여 독성 28일 | 랫드 군당 10 × 4군(부형제 · 저 · 중 · 고) = 40 · 비글견 군당 3 × 4군 = 12 | 종별 **NOAEL**(mg/kg/일) · 주요 소견(간 수치 상승 · QT 연장 등) | hERG · 간 위험 · 용량 부담 |
| 안전성약리(심장 · 중추 · 호흡) | 독성 시험 군에 함께 붙임(ICH M3(R2) 가 감소를 위해 권함) | QT 연장 여부 · 행동 변화 | hERG 위험 |

- 후보당 **적게 46 · 알맞게 82 · 많이 141마리**. 결과판에 후보별 · 모둠 합계 사용 마릿수를 늘 보인다.
- **군당 마릿수 수준 = 감소 원칙을 숫자로 겪게 한다**
  - 적게: 자료가 부족해 **안전계수 10 → 20**(FDA 2005 MRSD 지침은 '용량-반응 자료 부족 · 설계 미흡'이면 안전계수를 올리라고 한다) → 시작 용량 상한(MRSD)이 절반 → 3.3 에서 고를 수 있는 용량이 줄어 효능이 낮아진다.
  - 알맞게: 안전계수 10(기본).
  - 많이: 얻는 것이 없다(안전계수 그대로) — ② 심의가 '근거 없는 과다'로 보완을 요구한다.
- **NOAEL → HED → MRSD**(3.3 시작 용량의 근거 — FDA 2005 지침의 계산 그대로): `HED(mg/kg) = NOAEL ÷ 환산 계수(랫드 6.2 · 개 1.8)` → 두 종 중 **더 낮은 HED**(가장 민감한 종) → `MRSD(mg) = HED ÷ 안전계수 × 60 kg`. 화면은 이 계산 칸을 학생이 직접 채우게 하고(틀리면 어느 칸인지 짚음), 서버 값과 맞으면 계획서 · 3.3 신청서에 자동으로 붙는다.
  - 용어: NOAEL = 독성 시험에서 부작용이 보이지 않은 가장 높은 용량(mg/kg/일). HED = 사람 등가 용량(동물 용량을 사람 몸 기준으로 바꾼 값). MRSD = 사람 첫 투여의 최대 권장 시작 용량.
  - 예: 개 NOAEL 18 mg/kg/일 → HED 10 mg/kg → MRSD 약 60 mg(경구). 마릿수 '적게'면 MRSD 30 mg.
  - 'MRSD 이하 용량이면 IND 기준을 넘는다'는 보장이 있지만 1상 통과는 보장하지 않는다 — 'IND 승인은 출발 허락일 뿐'.
- **결정성**: 같은 (표적 버전 · 분자 · 설계)는 같은 결과. 다시 돌려도 결과가 바뀌지 않고 돈 · 동물만 더 들기 때문에 '다시 뽑기'가 없다 — 같은 설계 재실행 요청에는 과금 없이 옛 결과를 돌려준다.
- 비용 · 기간: 동물실험 묶음 후보당 400,000 크리스타 · 28게임 일(후보끼리 동시에 진행). 게임 시계로 끝난다.

### ⑤ 한 번 더 고르기 — 주력 · 백업 지정

- 결과판: 후보 열 × 지표 행(F% · 뇌/혈장 · 효력 % · 종별 NOAEL · 주요 소견 · **제형별 MRSD**(경구 · 정맥 · 경피) · 사용 마릿수). 대체 시험에서 뺀 후보는 흐린 열로 남긴다.
- 모둠이 **주력 1 + 백업 0~1** 을 정한다 — 둘 다 '유효 특허 + 동물실험 완료' 분자만, 주력과 백업은 서로 달라야 한다. 근거 칩(맞음 / 주의 / 막음):

| 근거 칩 | 판정 |
| --- | --- |
| 시작 용량을 넉넉히 잡을 수 있어요 | 경구 MRSD 가 후보 중 1위 맞음 · 아니면 **주의** |
| 질환 모델에서 기준 약만큼 들어요 | 효력 ≥ 기준 약 × 0.8 맞음 · 아니면 **막음** |

| 간 소견이 없어요 | 간 소견 없음 맞음 · 있으면 **막음** |
| 뇌까지 잘 가요(CNS 표적에만 보임) | 뇌/혈장 비 0.7 이상이면 맞음 · 아니면 **막음** |

- **동물실험 종료보고서**(자동 작성 + 학생 회고 한 줄, 200자 이하): 후보별 사용 마릿수 · 고통등급 · 인도적 종료 발생 수(고통등급 D 모델에서 위험이 큰 분자일수록 많음) · 대체 시험으로 덜 쓴 수.
- 3.2 완료 조건: 승인된 계획서 + 동물실험 1건 이상 완료 + 주력 지정.
- 선행 조건: 3.1 에서 유효 특허를 받아야 계획서 실행 · 시험이 열린다. 그 전에도 윤리 카드 읽기 · 계획서 칸 미리 쓰기는 된다.
- 전광판: `◆ {ticker} 전임상 완료 — {codeName} IND 준비`. 사용 마릿수 · 계획서 · 결과는 모둠과 교사만 본다(교사 화면에는 학급 합계 — 윤리 토론 자료).
